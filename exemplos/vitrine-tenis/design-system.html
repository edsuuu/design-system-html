Design system da vitrine

Tirado da loja conceito LAST DEPT. (ascentastudio.com/last-dept): cores, fontes, painel sem cartão e pílula. A luz das prateleiras, os tênis em SVG, a câmera em CSS e o tema claro foram desenhados aqui. A loja pronta está em index.html.

Os tênis

No lugar das fotos da referência, cada par é desenhado em SVG por Tenis.desenhar(modelo, indice), combinando cano (baixo, médio, alto), solado (plano, crua, grosso, ar, ondas), detalhe (faixa, traseira, painel, calcanhar, janela) e sete cores.

A câmera

A referência troca vídeos de aproximação; aqui é uma conta só. Para mostrar o nicho de centro (cx, cy) no ponto (alvoX, alvoY) da tela com escala s: translate(alvoX − cx·s, alvoY − cy·s) scale(s), com transform-origin: 0 0.

function camera(parede, palco, centroX, centroY, escala) {
  const { width, height } = palco.getBoundingClientRect();
  parede.style.transform = `translate(${width / 2 - centroX * escala}px, ${height / 2 - centroY * escala}px) scale(${escala})`;
}
