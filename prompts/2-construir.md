# Prompt 2: construir com o design system

Cole no agente, ajustando o pedido:

```
Faça <a página / o site / a tela> usando SÓ o design system de design-system.html.

- Use as variáveis, as classes, os componentes e as animações dele, por um CSS compartilhado
  (o mesmo que o design-system.html usa). Nada de estilo solto na página.
- Se faltar um componente ou efeito, acrescente-o primeiro no design-system.html (com a demo e o
  trecho), e só depois use-o na página.
- Conteúdo: <o que a página precisa dizer, seções, imagens>.
- Confira no navegador: desktop e 375 px, tema claro e escuro, prefers-reduced-motion, sem rolagem
  horizontal, sem erros no console.

No fim, diga o que foi acrescentado ao design system.
```
